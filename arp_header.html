🔄 Protocolo ARP

Encapsulación: ARP vs IP

Tráfico IP Normal
Ethernet Header (EtherType: 0x0800)
IP Header
TCP/UDP + Datos
Tráfico ARP ⚡
Ethernet Header (EtherType: 0x0806)
ARP Packet (¡Sin IP Header!)
⚠️ Nota importante: ARP va directamente en Ethernet, sin pasar por IP. Por eso se dice que está "entre" las capas 2 y 3.

Cabecera ARP (28 bytes)

Tamaño total: 28 bytes (para Ethernet + IPv4)
HLEN: Hardware address Length = 6 bytes (MAC)
PLEN: Protocol address Length = 4 bytes (IPv4)

Ejemplo: Funcionamiento de ARP

Escenario:

El PC con IP 192.168.1.100 (MAC: AA:BB:CC:DD:EE:FF) quiere comunicarse con 192.168.1.1 pero no conoce su MAC.

1️⃣ ARP Request (Broadcast):

Ethernet:
- MAC Destino: FF:FF:FF:FF:FF:FF (broadcast)
- MAC Origen: AA:BB:CC:DD:EE:FF
- EtherType: 0x0806 (ARP)

ARP:
- Operación: 1 (Request)
- MAC Origen: AA:BB:CC:DD:EE:FF
- IP Origen: 192.168.1.100
- MAC Destino: 00:00:00:00:00:00 (desconocida)
- IP Destino: 192.168.1.1 (la que buscamos)

2️⃣ ARP Reply (Unicast):

Ethernet:
- MAC Destino: AA:BB:CC:DD:EE:FF (unicast al solicitante)
- MAC Origen: 11:22:33:44:55:66
- EtherType: 0x0806 (ARP)

ARP:
- Operación: 2 (Reply)
- MAC Origen: 11:22:33:44:55:66 ✅
- IP Origen: 192.168.1.1
- MAC Destino: AA:BB:CC:DD:EE:FF
- IP Destino: 192.168.1.100
💡 Resultado: Ahora el PC sabe que 192.168.1.1 tiene la MAC 11:22:33:44:55:66 y guarda esta información en su tabla ARP (caché).
